# 👋 Olá, eu sou Henrique

## 🚀 Sobre mim

Sou desenvolvedor **Front-end**, com experiência em **desenvolvimento web, UX/UI e SEO técnico**.

Tenho uma base sólida em **HTML, CSS e JavaScript**, além de experiência com **React, Next.js e Astro**. Minha experiência com desenvolvimento Full Stack também me proporciona uma visão ampla sobre **backend, APIs, bancos de dados e integração entre sistemas**.

Gosto de construir aplicações e sites **rápidos, responsivos, acessíveis e bem estruturados**, equilibrando qualidade técnica, experiência do usuário e objetivos de negócio.

Atualmente, meu foco está em **Front-end, Next.js, desenvolvimento web, performance e SEO técnico**.
